- 本編: https://youtu.be/yMWuyfUbVKI
- ノーカット版: https://youtu.be/ARzaA4eKRAU

試行の回数: 129作品のうち、1回で完成が98本、2回が23本、3回が7本、7回が1本（#016。事前の全尺テストを数えた上限超過扱い）。

### B. QC は PASS だが、自己レビューで不合格・手直し: 約15件
QC では見つからない見た目の問題。`attempts.csv` の「問題:」に書かれていた。
- **文字**: 説明文が右端で切れた（幅を測らずに書いた #092）／背景の星の字が表示と重なり別の字に見えた（#114）／文字と飾り図形・UI が重なる（#003・#125）／左上の説明文の右端が枠から約12px はみ出す（#126。a01 で合格にして直していない）
- **体・向き**: 手前の腕が頭・顔の後ろに隠れる（#017）／前宙の着地で角度を -2π から線形に混ぜて体が逆さまに潜った（#019）／膝が壁に最大 0.22m めり込む（#019）
- **カメラ・主役**: カメラが傾き続け水平線が斜め・遠景ばかりで止まって見える（#034）／太陽が葉の塊に隠れ光の筋が見えない（#065）／波の爪が泡に隠れて塊に見える（#110）／最後のカードが0.8秒で消えて読めない（#012）
- **3D の見え方**: 下の帯が暗い板と同じ奥行きで重なりかすれる Z ファイティング（#100）
- **シミュレーションの調整**: 硬すぎて変形が見えない／柔らかすぎて輪郭が折れる（#046 a01→a02→a03 で面積比 0.998〜1.000・折れ1〜3点に）
- **書き出し前のテスト**で直したもの（試行に数えない）: 位置・大きさ・明るさ・ぼけ・映り込み・シード選び（#096 シード29）など。ここで直すほど試行が減る
