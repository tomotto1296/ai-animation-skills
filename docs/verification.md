# 検証（T1〜T8）の結果

新しい8つのお題を、新しいセッションが、公開した4つのスキルだけを頼りに作りました（Claude Sonnet 5.5）。狙いは「過去に落ちた型に、またはまらないか」です。
お題の指示文: 長さ10秒前後、1920×1080・30fps、外部素材なし（コードだけ）、試行の上限3回、時刻は実測。各試行の記録は [`examples/verification-runs/results.csv`](../examples/verification-runs/results.csv)。

| お題 | 試行 | 1回目で完成 | 狙った落とし穴 | 手戻りの理由・補足 |

## 読み取り
- 1回目で完成: 3/8（T5・T6・T7）。試行は合計14回（平均1.75回）。129作品の記録（平均1.29回）より多いが、**条件が厳しい**（QC と自己レビューの両方を1回目の合格にした、お題を落とし穴狙いで選んだ、絵の質まで検査した）
- 狙った落とし穴（ちらつき・黒・白・静止・角度・流れ・文字・物理）は、T8 の QC の見逃しを除き、1回目から出なかった
- 手戻りの理由は一貫して「絵の質」（T1〜T4 の a01）と、止まった後の動きの設計（T8）。QC を通ることと、見た目が良いことは別
- 1回目で完成した3本の共通点は、描く前または draft の段階で、数値で採用基準を決めて検査したこと
- 8本という少ない数で、統計にはなりません

## 注意書き / Note
※ 129本の制作は Claude Opus 5.5 で行いました。スキルはその記録をまとめたもので、今回の検証（8本）は Claude Sonnet 5.5 のみで行っています。スキルなしの Sonnet 5.5 との比較や、Opus 5.5 との比較はしていません。8本という少ない数での結果です。

Note: The 129 works were made with Claude Opus 5.5. The skills summarize those records; the verification (8 works) used Claude Sonnet 5.5 only. I did not compare against Sonnet 5.5 without the skills, nor against Opus 5.5. This is a small sample of 8 works.
